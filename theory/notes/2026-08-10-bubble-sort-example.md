Consider bubble sort.

One implementation of bubble sort is as follows.

<br>

$Algorithm \ \alpha(A, n):$\
$\quad Input: A \ is \ an \ array \ of \ numbers$\
$\quad Output: Return \ the \ sorted \ array \ A$

$\quad For \ i \ in \ 1 .. n: $\
$\quad \quad For \ j \ in \ 1 .. n - i: $\
$\quad \quad \quad If \ A[j] > A[j+1]: $\
$\quad \quad \quad \quad Swap(A[j], A[j+1])$

$\quad Return \ A$
